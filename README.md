## What it does

`main.py` writes a single-line, under-160-character out-of-office reply to `entry.txt` in the output directory. The output directory is resolved from `MAKEFUN_OUTPUT_DIR` when set, otherwise from `MAKEFUN_BOT_DIR` when set, otherwise `/output`.

## Run

```sh
python3 main.py
```
